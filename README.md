# Fingers

A tiny offline-first PWA that randomly picks the first player for a tabletop game by touch. Place fingers on the screen; after a few seconds one is highlighted.

Lives at **[fingers.42.uy](https://fingers.42.uy)**.

## How it works

Each player puts a finger on the screen. Once nobody is adding or removing fingers for about three seconds, the app picks one finger at random and highlights it. When everyone lifts, the screen resets and a new round can begin. Nothing is stored between rounds.
